가치고 개인정보 처리방침

시행일: 2026년 3월 21일

1. 개인정보 수집 항목

가치고(이하 "앱")는 서비스 제공을 위해 다음 정보를 수집합니다:

  • 계정 정보: 이름, 이메일 (OAuth 로그인 시 제공되는 정보)
  • 위치 정보: 여행 중 실시간 위치 공유 기능 사용 시 (사용자 동의 하에)
  • 여행 데이터: 여행 일정, 숙소, 교통, 경비 등 사용자가 직접 입력한 정보
  • 사진: 사용자가 업로드한 여행 사진

2. 개인정보 수집 목적

  • 여행 계획 생성 및 관리
  • 여행 멤버 간 실시간 위치 공유
  • 여행 일정 협업 및 공유
  • 경비 분할 및 관리

3. 위치 정보 사용

앱은 다음 목적으로 위치 정보를 사용합니다:

  • 여행 중 멤버 간 실시간 위치 공유 (사용자가 명시적으로 활성화한 경우에만)
  • 주변 관광지/맛집 검색

위치 정보는 사용자가 기능을 비활성화하면 즉시 수집이 중단됩니다.

4. 개인정보 보관 및 삭제

  • 계정 삭제 요청 시 모든 개인정보가 즉시 삭제됩니다.
  • 위치 데이터는 여행 종료 후 자동 삭제됩니다.

5. 제3자 제공

앱은 사용자의 개인정보를 제3자에게 판매하거나 공유하지 않습니다. 다만 다음 서비스를 통해 데이터가 처리될 수 있습니다:

  • 카카오 로그인 (인증)
  • Google Maps API (지도 표시)
  • Google Cloud (서버 인프라)

6. 보안

앱은 SSL/TLS 암호화, JWT 토큰 기반 인증, 비밀번호 해시화 등의 보안 조치를 적용합니다.
